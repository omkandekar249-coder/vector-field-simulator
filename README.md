# vector-field-simulator
A NumPy-based tool to visualize vector fields. A project I originally made in high school (Feb 2026) while studying Calc 3. The tool lets you visualize vector fields of the form: F(x,y) = (P(x,y), Q(x,y))

The program asks you for: 
-  P(x,y)
-  Q(x,y)
-  The x-range
-  The y-range
-  Density

To run: 
  main.py

Example Input:
- P(x, y) = y
- Q(x, y) = -x
- xmin = -5
- xmax = 5
- ymin = -5
- ymax = 5
- density = 25

Libraries Used:
- Numpy
- Matplotlib
